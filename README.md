# Analyzer Excel

#📊 PR. 2 Analyzer Dashboard Project

## About

- PR. 2 Analyzer is an advanced Excel-based data analytics project designed to perform business analysis, sales insights, and dashboard reporting using real-world datasets.

- This project demonstrates important Excel concepts such as Conditional Formatting, WHAT-IF Analysis, Pivot Tables, Regression Analysis, Data Visualization, and Dashboard Creation while improving analytical thinking and data interpretation skills.



## Features

- Interactive sales and profit dashboard

- Conditional Formatting for Top 10 customers

- WHAT-IF Analysis for profit impact prediction

- Linear Regression analysis using Data Analysis ToolPak

- Descriptive Statistical Analysis

- High-value customer identification system

- Monthly sales growth tracking with arrows/symbols

- Region-wise product performance analysis

- Pivot Tables for business reporting

- Bar Charts, Line Charts, and Pie Charts visualization

- Timestamp generation using NOW() function

- Business KPI analysis and storytelling



## Concepts Used

- Conditional Formatting

- WHAT-IF Analysis

- Pivot Tables & Pivot Charts

- INDEX & MATCH Functions

- Data Analysis ToolPak

- Linear Regression

- Descriptive Statistics

- Dashboard Design

- Data Visualization

- Custom Number Formatting

- Excel Functions & Formulas

- Business Data Analytics



## Technologies Used

- Microsoft Excel

- Excel Data Analysis ToolPak



## Purpose

The main purpose of this project is to analyze business sales data and create an interactive analytical dashboard using advanced Excel features.

It helps improve data analysis skills, dashboard designing, business reporting, visualization techniques, and real-world problem-solving abilities through practical implementation.
